# SSE PILI (Frontend)
 
 
## Requirements
 
- [Node.js](https://nodejs.org/) v18 or newer (LTS recommended)
- npm (comes with Node.js)
- Git
- The backend API running locally or reachable over the network
Check your versions:
 
```bash
node -v
npm -v
git --version
```
 
## 1. Clone the repository
 
```bash
git clone <REPO_URL>
cd <PROJECT_FOLDER>
```
 
## 2. Install dependencies
 
```bash
npm install
```
 
## 3. To run project
```bash
npm run dev
```
